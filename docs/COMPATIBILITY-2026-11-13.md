# Compatibility update: November 13, 2026

Signed catalog revision 3 adds the original Heat Live 6.0.0 and HeatVod 6.9.9 packages found on the V6. It also retains the earlier supported versions. The Vsee App Builder installer remains version 0.7.16. Owners with that version can select **Check compatibility** while online to receive the new entries; no new builder APK is required.

The new templates were matched to the exact original package hashes and checked for neutral placeholders before publication. Builder 0.7.16 fetched the new catalog on the V6 and marked all six installed originals as matched. Private test APKs installed on the source V6. HeatVod reached its home screen. Heat Live reached Android's first-run media permission prompt without a crash. The builder's Make APKs action and playback on a separate device have not been checked for these two versions.

An update with a different package fingerprint still requires review and another signed catalog revision. Do not share the APKs generated from an owner's box; they contain that box's profile.
