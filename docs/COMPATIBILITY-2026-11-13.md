# Compatibility update: November 13, 2026

Signed catalog revision 3 adds the original Heat Live 6.0.0 and HeatVod 6.9.9 packages found on the V6. It also retains the earlier supported versions. Builder 0.7.16 can fetch these entries through **Check compatibility** while online. Builder 0.7.17 additionally fixes export when a separate root ADB session is already open.

The new templates were matched to the exact original package hashes and checked for neutral placeholders before publication. Builder 0.7.17 marked all six installed originals as matched and saved all six selected APKs to Downloads while the separate root ADB session stayed connected. Private test APKs installed on the source V6. HeatVod reached its home screen. Heat Live reached Android's first-run media permission prompt without a crash. Playback on a separate device has not been checked for these two versions.

An update with a different package fingerprint still requires review and another signed catalog revision. Do not share the APKs generated from an owner's box; they contain that box's profile.
